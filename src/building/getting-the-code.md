# Getting the code

To build Aether or change it, clone [the browser repository](https://github.com/AetherBrowser/aether) with Git:

```sh
$ git clone https://github.com/AetherBrowser/aether.git
$ cd aether
```

<div class="warning _note">

**The repository is pretty big!**
It contains the Servo engine as well as `ports/aether`.
If you have an unreliable network connection or limited disk space, consider [making a shallow clone](https://github.blog/2020-12-21-get-up-to-speed-with-partial-clone-and-shallow-clone/).

</div>


Once you've cloned the source, the [next step is to install dependencies and build Aether](building.md).
