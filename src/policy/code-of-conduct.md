# Code of Conduct

AetherBrowser follows the [Rust Code of Conduct](https://rust-lang.org/policies/code-of-conduct/).
It applies to the AetherBrowser GitHub repositories and the other spaces the project uses.

If you are subject to or witness unacceptable behavior, report it to the maintainers of [AetherBrowser/aether](https://github.com/AetherBrowser/aether):

  - Axel Battigelli (he/him) <axel.battigelli@epitech.eu>
  - Corentin Bergaentzle (he/him) <corentin.bergaentzle@epitech.eu>
