# Getting Started

AetherBrowser welcomes contributions from everyone.
Working on a browser and its engine can be challenging and sometimes frustrating, but it can also be very rewarding and fun.
If you spend the time and effort to get involved, you will constantly be learning and growing as a developer and open source contributor.
To get started, please do the following:

1. Familiarize yourself with the [Code of Conduct](../policy/code-of-conduct.md) and [AI usage guidelines](../policy/ai-usage.md).
2. Read the rest of this page for basic information about contributing to Aether.
3. Successfully [fetch the Aether repository](../building/getting-the-code.md) and build Aether.
4. Set up your fork and learn the basics of using Git, following the contents of our [Git Setup](git-setup.md) chapter.
5. Learn a bit of Rust.
   There are many resources online for how to do this, but one of the best is the official [Learning Rust documentation](https://doc.rust-lang.org/stable/#learning-rust).
   If you are familiar with other imperative programming languages, you can learn Rust as you work on Aether, but having a basic familiarity with the language is very useful to get started.
6. [Set up your editor](editor-setup.md) so that it integrates with `rust-analyzer`.
7. Read our [Style Guide](style-guide.md) for expectations about the code you contribute.
8. Read and follow the [steps for making a pull request](making-a-pull-request.md).

## Working on an issue

Should you wish to work on an issue, leave a comment on it in [AetherBrowser/aether](https://github.com/AetherBrowser/aether) so other contributors can see that you have claimed it.

Look through the open issues there to find a task.
If you find any unfamiliar words or jargon, please check [the glossary](../old/glossary.md) first.
If there's no matching entry, please make a pull request to add one with the content `TODO` so we can correct that!
